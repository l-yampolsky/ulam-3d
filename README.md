# ulam-3d

Interactive 3-D visualization of prime numbers on a cubic-shell analogue of the Ulam spiral.

The program places the positive integers on successive cubic shells of the integer lattice and uses Plotly to display prime numbers in an interactive 3-D view. The figure can be rotated manually or automatically, switched between black and white backgrounds, colored by prime value or residue class, and explored shell by shell.

## Features

- Interactive 3-D rotation and zoom
- Automatic rotation animation with play/pause controls
- Shell-radius slider
- Black / white background switch
- Prime coloring by:
  - numerical value
  - residue modulo 6
  - residue modulo 30
- Optional display of prime powers
- Optional faint display of other composite numbers
- Hover labels showing integer values and coordinates

## Installation

Python 3.9+ is recommended.

```bash
python3 -m pip install numpy plotly
```

or:

```bash
python3 -m pip install -r requirements.txt
```

## Run

```bash
python3 ulam3d.py
```

The Plotly visualization should open in a web browser or compatible interactive viewer.

The default maximum integer is:

```python
N = 100_000
```

Change this value in `ulam3d.py` to explore larger or smaller ranges. Larger values may require substantially more memory and rendering time.

## Mathematical construction

The construction uses successive cubic shells

```text
max(|x|, |y|, |z|) = r
```

around the origin. The shell of radius `r` contains

```text
(2r + 1)^3 - (2r - 1)^3 = 24r^2 + 2
```

lattice positions.

The ordering is based on a 3-D square/cubic spiral construction related to OEIS A343640:

https://oeis.org/A343640

The purpose here is exploratory visualization: the program does not claim that any apparent planes, filaments, or other structures constitute new mathematical results.

## Prime powers

Prime powers are shown separately when enabled. These are composite integers with only one distinct prime factor:

```text
4 = 2^2
8 = 2^3
9 = 3^2
25 = 5^2
27 = 3^3
...
```
